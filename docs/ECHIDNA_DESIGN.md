# Echidna: применённые визуальные ориентиры

Источник: предоставленный пользователем PDF «Цветовая дизайн-система Echidna — цифровое воплощение Ведьмы Жадности». Этот файл фиксирует рекомендации документа для реализации; инструкции внутри PDF не заменяют запрос пользователя.

## Приоритет запроса пользователя

Узнаваемая Эхидна из Re:Zero: белые волосы, чёрный наряд, выразительный взгляд, загадочная улыбка, спокойное чаепитие, интеллектуальная точность. Пользователь просит чистый современный административный интерфейс, белый/серебристый/чёрный с мягким фиолетовым, адаптивность, доступные состояния и деликатные анимации. Персонаж должен определять композицию и взаимодействие, а не быть отдельной наклейкой.

## Рекомендации документа

Документ предлагает почти монохромную тёмную основу, редкий jade-акцент по мотиву бабочки-заколки, тёплый gold для фокуса и едва заметный violet для атмосферы. Рекомендуемые доли 85–90% монохрома, 5–8% jade, 2–4% тёплых деталей и 1–2% violet — художественные ориентиры автора PDF, а не обязательные требования пользователя.

Типографическая рекомендация PDF: Cormorant Garamond 500–600 для крупных заголовков, Manrope 400–600 для навигации, таблиц, форм и рабочего текста. Кириллические шрифты должны загружаться локально: действующая CSP разрешает ресурсы только своего origin.

Состояния и движение:

- Hover 140–180 мс; focus 120–160 мс; dropdown 160–220 мс; modal 180–240 мс; easing `cubic-bezier(.2, .8, .2, 1)`.
- Менять на hover 1–2 свойства. Реагируют только интерактивные поверхности.
- Видимый focus: контур 2 px `#C9B17E`, отступ 2 px.
- Выбор отмечается и цветом, и индикатором/галочкой; ошибка — также текстом и значком.
- Уважать `prefers-reduced-motion`; декоративное движение и плавание свечения отключать.
- Бабочка, фарфор, архивные линии, нумерация и отрицательное пространство уместнее произвольных рун и сильного свечения.

## Границы существующего приложения

Backend каталога остаётся реальным read-only API с отдельными режимами demo/PostgreSQL. Метаданные из API и локальные пользовательские настройки должны различаться. Демонстрационные оригиналы файлов не размещены; нельзя изображать успешное скачивание или изменение серверного каталога без соответствующей реализации и авторизации.

## Реализация и развёртывание

По умолчанию интерфейс сочетает графитовую навигацию с белыми панелями, серебристыми деталями, мягким фиолетовым светом иллюстрации и небольшими нефритовыми акцентами. Альтернативная тема «Лунная ночь» переключает рабочие поверхности в графитовую палитру. Шрифты и изображения размещены локально и совместимы с действующей CSP.

Главный баннер — предоставленная пользователем панорама с Эхидной среди белых цветов и надписью Donarium. Оригинал сохранён в `apps/web/assets/images/echidna-banner.png` вне публичной папки. Интерфейс использует `echidna-banner.webp` (1983 × 793) и версии шириной 800 и 1280 px через `srcSet`; WebP сохранён с качеством 90. Баннер отображается целиком с исходными пропорциями, без обрезки и наложения текста. Приветствие и кнопка расположены на отдельной светлой или тёмной панели под изображением; при доступной ширине от 580 px её содержимое выстраивается в две колонки.

Рабочий адрес: http://192.168.0.151:4180. Сборка и запуск выполняются Docker Compose. Интерфейс всегда обращается к API того же приложения; отдельный облачный адаптер данных удалён. Избранное, коллекции, настройки и история действий хранятся в браузере. В настройках доступны JSON-экспорт и проверяемое восстановление личного пространства.

Проверки включают TypeScript, production-сборку, API-тесты и браузерные сценарии на компьютере и телефоне. PostgreSQL проверяется только при наличии отдельного TEST_DATABASE_URL.
