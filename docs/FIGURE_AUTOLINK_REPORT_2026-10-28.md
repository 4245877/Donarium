## Охват и архитектура

Приложение: React/TypeScript, Fastify, PostgreSQL. Штатный механизм — `saveFigureFile`, `assets.file_id`, `assets.metadata.role = "figure"`, логический корень `LIBRARY` и относительный путь в `storage_files`. Уникальные индексы защищают одну активную роль figure на товар и отсутствие повторной пары товар/файл. Библиотека подключена через NFS только для чтения.

Проверены исходный `/srv/data/google-drive/Идеально`, соседний каталог загрузчика, uploads, work, inventory, quarantine и пользовательские каталоги `.141`. Bind-представления одной библиотеки повторно не считались. Вне библиотеки готовых пакетов фигурок не найдено: work содержит четыре служебных metadata ZIP, в домашнем каталоге обнаружены один тестовый STL и 18 GZ с данными инструментов. Это не кандидаты для товаров. Карантин, `/media`, `/mnt`, `/opt` пусты. Итоги дополнительных обходов: [other-roots-scan.json](../var/qa/figure-autolink-20261028/other-roots-scan.json).

## Критерии автоматической записи

Исходные имена из описаний, импортированных записей и внешних вложений должны согласовываться. Допускается нормализация Unicode, регистра и разделителей; сохраняются автор, номера, версии, формат и варианты комплектации. Кандидат должен быть единственным, доступным и согласованным с реестром и прежней полной SHA-256-описью.

Дополнительно требуется читаемое оглавление, реальные модели внутри пакета, подтверждение конкретного персонажа/версии по именам моделей и папок, отсутствие противоречий названиям и категориям. Явно заявленные supported/unsupported, NSFW, bust, chibi и другие варианты проверяются отдельно. Для составной композиции проверяются участники. Нечёткие совпадения и транслитерация служат только ориентиром при анализе; они не разрешают автоматическую запись.

Без новой привязки оставлены, в частности:

- Два разных `2B_-_Nier_Automata.rar`, различающихся регистром, и недостаточно конкретные варианты одного персонажа.
- «Зоро — Ван пис»: исходный файл содержит `Goku`.
- «Невидимка — Люди Х»: исходный файл обозначает Invisible Woman; требуется уточнение.
- Три карточки с категорией Genshin Impact и явно обозначенным Honkai в пакете.
- Неподтверждённые составные композиции, варианты NSFW/chibi и многотомный `Galactic_Soldier.part1.rar`.
- Пакеты, в которых доступны только вложенные архивы либо имена деталей не подтверждают фигурку. Вложенные модели не распаковывались на сервере.

Причины могут пересекаться: 71 карточка не имеет достаточного подтверждения по именам деталей, у 59 исходное имя недостаточно различает версии, у 35 нет непосредственно проверяемых моделей. Эти числа не складываются в общий итог.
