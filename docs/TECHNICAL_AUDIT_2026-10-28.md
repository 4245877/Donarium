### Подтверждённые ошибки и исправления

Каждая проблема воспроизведена до исправления. Четыре новых теста падали на исходном коде; отдельное расширение проверки обложки также падало. Все воспроизведения используют изолированные данные. В рабочем каталоге эти ошибки не исправлялись изменением пользовательских записей.

| Ошибка | Причина и подтверждение | Исправление |
|---|---|---|
| Замена/снятие роли фигурки удаляла ранее существовавшее вложение | `saveFigureFile` переиспользовал asset, но затем безусловно удалял прежний asset. Тест `replacing or detaching a figure preserves an attachment which existed before selection` терял исходный UUID после замены | Для переиспользованного вложения сохраняется служебная отметка; при снятии роли удаляются только роль и отметка. Специально созданная связь фигурки по-прежнему отвязывается, файл и реестр сохраняются. Повторный выбор не теряет отметку. Проверено полное равенство прежней строки вложения после замены и отвязки |
| Импорт папок игнорировал MAX/TAR/GZ | Список форматов расходился с полем фигурки. Тест сканирования трёх таких папок возвращал пустой preview | Импорт использует общий `FIGURE_FILE_EXTENSIONS`; проверены preview и создание трёх тестовых карточек без ошибок |
| Сбой получения фоновой блокировки удерживал соединение PostgreSQL | Ошибка первого `pg_try_advisory_lock` происходила до блока освобождения. Fault injection показал 0 вызовов release вместо 1 | Соединение освобождается на всех путях; при неопределённом результате lock/unlock сессия закрывается, чтобы удерживаемая блокировка не вернулась в пул |
| Прерывание проверки файла записывало ложное `unavailable` | Исключение отмены из hash callback перехватывалось как файловая ошибка. Проверка не отклонялась и меняла статус | Отмена проверяется до работы, при обработке ошибки и перед UPDATE; статус и остальные поля при отмене сохраняются. Сверена вся строка реестра |
| Скрытое изображение принималось как обложка | Проверка принадлежности учитывала карточку и kind, но не `retired_at`; последующий thumbnail такого asset возвращает 404 | Выбирать можно только активные изображения. Расширен тест атомарности редактирования и принадлежности обложки |

### Оставшиеся ограничения

- У systemd recovery сохраняется известное ограничение обычного `stop`: поздний `OnFailure` NFS mount способен инициировать запуск включённого сервиса. Исходные и рабочие units в этом аудите не менялись. Для гарантированного обслуживания README предписывает `systemctl disable --now donarium.service`, затем `enable --now`. Это исправление процедуры эксплуатации, а не устранение ограничения обычного stop.
- Независимая полная копия всех оригиналов на другом физическом носителе не подтверждена. Новые source/dump/metadata backup защищают код и метаданные; они не заменяют отдельный backup 394-ГиБ библиотеки. Оригиналы не копировались повторно без подходящего назначения.
- Hard NFS способен ждать внутри системного вызова дольше лимита поиска. Реальные отключения сети, аварийное питание и перезагрузка серверов не имитировались. Проверены guards, режимы mounts и существующие изолированные сценарии отказов.
